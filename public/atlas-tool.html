CS:GO Food & Drink Sprite Atlas Maker

Công cụ tạo file WebP Sprite Atlas (1448 x 1086 px) chuẩn CS:GO để gắn ảnh cho món ăn và nước uống.

Hướng dẫn nhanh:
1. Chọn bộ Atlas tương ứng từ dropdown phía trên.
2. Kéo thả hoặc click chọn hình ảnh vào 12 ô (mỗi ô tương ứng 1 món). Bạn có thể để trống các ô chưa có ảnh.
3. Nhấn Tải xuống file WebP để lưu file (ví dụ drinks-0.webp).
4. Copy file vừa tải vào thư mục public/ của dự án.
5. Mở file src/app/page.tsx, thêm tên file vào danh sách AVAILABLE_ATLASES (ví dụ: thêm 'drinks-0') để kích hoạt ảnh trên giao diện!
